本指南分为三部分：

- [一、组织者：创建比赛项目](#part1)
- [二、裁判：录入比分](#part2)
- [三、观众：查看比分](#part3)
- [常见问题](#faq)

系统功能：根据分好组的名单自动生成**小组循环赛表**，裁判在线录入比分，小组赛结束后**自动生成淘汰赛对阵**，直至决出冠军。所有数据保存在本网站的 GitHub 仓库中，无需其他服务器。

<h2 id="part1">一、组织者：创建比赛项目</h2>

一个赛事可以有多个项目（如男子单打 A 级别、女子双打），**每个项目对应一个配置文件**。

### 第 1 步：新建项目配置文件

在仓库的 `_data/events/` 目录下新建一个 `.yml` 文件。文件名就是**项目 id**，只用英文字母、数字和 `-`，例如：

| 项目 | 文件名 | 项目 id |
|---|---|---|
| A级别男子单打 | `_data/events/2026-ms-a.yml` | `2026-ms-a` |
| 女子单打 | `_data/events/2026-ws.yml` | `2026-ws` |
| 男子双打 | `_data/events/2026-md.yml` | `2026-md` |

最简单的做法是复制 `_data/events/demo.yml` 再修改。

### 第 2 步：填写名称和分组

```yaml
name: A级别男子单打

groups:
  A: [张伟, 王磊, 李强, 刘洋]
  B: [陈杰, 杨帆, 赵鹏, 黄涛]
  C: [周斌, 吴昊, 徐亮, 孙浩]
  D: [马超, 胡军, 郭峰, 何勇]
```

- 组名建议用 `A`、`B`、`C`……
- 双打项目每队写成 `张三 / 李四`；
- 名单中的先后顺序就是表格中的显示顺序，也是所有排名条件都相同时的最后排序依据（可按种子顺序填写）；
- 系统根据名单自动生成每组的**比赛顺序**：4 队一组打 3 轮，5 队一组打 5 轮且每队正好轮空 1 次；名单中第 1、2 位在最后一轮相遇；
- 每组人数可以不同。

### 第 3 步：设置规则

```yaml
rules:
  advance: 2
  points: { win: 1, loss: 0, wo_loss: 0 }
  tiebreakers: [points, h2h, set_diff, game_diff]
  third_place: true
  show_order: true
  score_hint: "如 6-4 或 7-6(5)"
```

| 设置 | 说明 |
|---|---|
| `advance` | 每组前几名进入淘汰赛。`0` 表示只打循环赛，没有淘汰赛 |
| `points` | 胜 / 负 / 弃权负 各得几分 |
| `tiebreakers` | 小组排名依据，按顺序比较（见下表） |
| `third_place` | `true` 加打三四名决赛，`false` 不打 |
| `show_order` | `true` 在每组下方显示"比赛顺序"（默认收起，点击展开）；`false` 或不填则不显示 |
| `score_hint` | 录入比分时的提示文字（可选） |

排名依据可选值：

| 值 | 含义 |
|---|---|
| `points` | 积分 |
| `wins` | 胜场数 |
| `h2h` | 同分选手之间的相互战绩 |
| `set_diff` | 净胜盘 |
| `game_diff` | 净胜局 |
| `set_ratio` | 胜盘率 |
| `game_ratio` | 胜局率 |
| `sets_won` | 胜盘数 |
| `games_won` | 胜局数 |
| `games_lost` | 负局数（少者排名靠前） |

多人同分时：某项条件分出部分名次后，剩下仍同分的选手**从第一项条件重新比较**（ITF 方式）。

### 第 4 步（可选）：指定淘汰赛对阵

不填写时系统会**自动生成**：各组第 1 名为种子，同组选手尽量分在不同半区，人数不足时自动轮空。

如需自己指定首轮对阵，在 `rules` 下加入 `draw`：

```yaml
  draw:
    - [A1, C2]
    - [D1, B2]
    - [B1, D2]
    - [C1, A2]
```

- `A1` = A 组第 1 名，`C2` = C 组第 2 名；
- `BYE` = 轮空，对手直接晋级；
- 也可以直接写选手姓名；
- 从上到下依次是第 1、2、3、4 场，相邻两场的胜者在下一轮相遇。

### 第 5 步：把项目放到页面上

在任意页面（例如 `2026/1115.md`）中加入一行：

{% raw %}
```liquid
{% include event.html id="2026-ms-a" %}
```
{% endraw %}

一个页面可以放多个项目：

{% raw %}
```liquid
---
layout: page
title: "2026 ACTC 单打赛程"
wide: true
---

- [A级别男子单打](#event-2026-ms-a)
- [女子单打](#event-2026-ws)

{% include event.html id="2026-ms-a" %}

{% include event.html id="2026-ws" %}
```
{% endraw %}

- 页面头部加 `wide: true`，表格的显示空间会更宽；
- 每个项目的标题自动带有锚点 `#event-<项目id>`，可以像上面那样做目录链接。

### 第 6 步：发布

提交（commit）并推送（push）到 GitHub，约 1～2 分钟后网站自动更新，页面上就会显示分组表和淘汰赛对阵表。

比分文件 `events/scores/<项目id>.json` **不需要手动创建**，第一次录入比分时会自动生成。

### 第 7 步：为裁判创建登录令牌

裁判录入比分需要一个 GitHub 令牌（token）。由仓库管理员创建：

1. 登录 GitHub，点击右上角头像 → **Settings**；
2. 左侧最下方 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**；
3. 填写：
   - **Token name**：如 `2026-referee`
   - **Expiration**：设置到比赛结束后几天即可
   - **Resource owner**：`tennis4acta`
   - **Repository access**：选 **Only select repositories** → `tennis4acta.github.io`
   - **Permissions → Repository permissions → Contents**：选 **Read and write**（其他权限都不用开）
4. 点击 **Generate token**，复制生成的令牌（以 `github_pat_` 开头，只显示一次）；
5. 把令牌私下发给裁判，**不要发到群里或公开的地方**。

> 持有令牌的人可以修改本网站的内容，请只交给可信的裁判，比赛结束后在同一页面中删除（Delete）该令牌。

### 开赛前检查清单

1. 所有项目页面能正常打开，分组和选手姓名无误；
2. 用令牌登录，随便录入一场比分，确认能保存成功，然后点"清除比分"删掉；
3. 确认已删除或替换演示文件 `events/demo.md` 和 `_data/events/demo.yml`。

> **开赛后不要修改项目 id 和选手姓名**。改了 id，该项目会去读另一个比分文件；改了姓名，该选手已录入的比分会失效。

<h2 id="part2">二、裁判：录入比分</h2>

### 第 1 步：登录

1. 用手机或电脑打开比赛页面；
2. 点击右上方的 **裁判登录**；
3. 粘贴组织者提供的令牌，点 **登录**；
4. 登录成功后按钮变为 **退出计分（你的用户名）**，表格中出现可点击的格子。

同一台设备只需登录一次，同一页面上的所有项目都可以录入。

### 第 2 步：录入小组赛比分

1. 在小组表中找到**该行选手**与**该列对手**相交的格子（空白格子显示为 `+`），点击；也可以展开表格下方的"比赛顺序"（若已开启）直接点击对应的比赛；
2. 在弹出窗口中输入比分，**以弹窗中第一位选手的视角**填写；
3. 系统根据比分自动判断胜者，确认后点 **保存**。

比分写法：

| 情况 | 写法 |
|---|---|
| 一盘 | `6-4` |
| 抢七 | `7-6(5)` |
| 三盘两胜 | `6-4 3-6 6-2` |
| 第三盘抢十 | `6-4 3-6 [10-8]` |

特殊情况在"结果"中选择：

| 结果 | 操作 |
|---|---|
| **中途退赛（RET）** | 填写已完成的比分（可留空），然后**手动选择胜者** |
| **弃权（W/O）** | 不用填比分，**手动选择胜者** |

### 第 3 步：小组赛结束 → 淘汰赛

- 某个小组的所有比赛录完后，该组出线选手**自动填入**淘汰赛对阵表；
- 出线选手在小组表中显示为绿色行；
- 尚未确定的位置显示为"A组第1名""第3场胜者"等。

### 第 4 步：录入淘汰赛比分

在淘汰赛对阵表中，双方都确定的比赛会显示 **录入** 按钮，点击后录入方法与小组赛相同。胜者自动进入下一轮；决赛结束后页面显示冠军、亚军（和季军）。

### 修改或删除比分

- 点击已有比分的格子，或淘汰赛中的 **修改**，改好后保存；
- 点击 **清除比分** 可删除该场结果；
- 如果修改了小组赛比分，导致出线选手变化，相关淘汰赛比分会自动失效，需要重新录入。

### 第 5 步：退出

比赛结束或更换设备后，点击 **退出计分**，令牌会从该设备上删除。

<h2 id="part3">三、观众：查看比分</h2>

- 直接打开比赛页面即可，无需登录；
- 页面**每 60 秒自动刷新**，也可以点 **刷新** 按钮立即更新；
- 顶部显示比赛状态（小组赛进行中 / 淘汰赛进行中 / 比赛结束）和最后更新时间；
- 小组表中的比分以**该行选手**的视角显示，绿色为胜，红色为负；
- 开启时，每组下方的"比赛顺序"（点击展开）列出每一轮的对阵和轮空队伍，已完成的比赛会显示比分；
- 现场多人共用同一个 Wi-Fi 时，比分可能延迟几分钟显示，属正常现象。

<h2 id="faq">常见问题</h2>

**Q：登录时提示"令牌无效"？**
令牌复制不完整或已过期，请向组织者重新获取。

**Q：保存时提示"没有写入权限"？**
创建令牌时未选择本仓库，或 Contents 权限不是 Read and write，请组织者重新创建。

**Q：保存时提示"冲突"？**
另一位裁判刚好同时保存，系统已自动重试；仍然失败时再点一次保存即可。

**Q：录错了比分怎么办？**
点击该场比赛修改或清除即可。所有修改都记录在 GitHub 的提交历史中，必要时组织者可以恢复。

**Q：修改了分组名单，页面没变化？**
修改 `_data/events/` 下的文件后需要推送到 GitHub，并等待 1～2 分钟网站重新生成。

**Q：小组排名完全相同（所有条件都一样）怎么办？**
按配置文件中的名单顺序排列。如需抽签决定，可调整名单中这几位选手的先后顺序（只调整顺序，不要改名字）。

**Q：能否用于双打？**
可以，每队写成 `张三 / 李四`，用法与单打完全相同。
